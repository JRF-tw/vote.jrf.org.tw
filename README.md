# 年度司法大事記

民間司法改革基金會（司改會）每年整理當年度台灣重要的司法事件，邀請大家一起回顧，並圈選出心中最重要的幾件。

網站：https://vote.jrf.org.tw/

## 網站內容

- **票選年度司法大事**：依時間順序回顧當年度的司法事件，每人最多圈選 5 件。
- **年度結果**：圈選截止後，公布「大家心中的年度大事」與「司改會評選」的對照。
- **歷年回顧**：保存每一年的事件與結果。
- **司法民調**：整理司法院、中正大學犯罪研究中心、遠見等單位的司法相關民調，附原始出處。中正大學調查專頁位於 `/#ccu-survey`，提供2018–2025年六項指標的互動圖表、年度數據及來源。

## 圈選資料怎麼處理

圈選事件後，按「完成我的清單」，在視窗填寫 Email 即可送出，不需要登入或跳到 Google 表單。Email 必填，並檢查基本格式（例如 name@example.com），只用來核對投票資料，結果公布後刪除。同一個瀏覽器送出後無法再次投票。

## 免責聲明

事件內容依公開的新聞報導、判決與官方資料整理，不是法律意見。尚未判決確定的案件，被告依法推定無罪；列入大事記不代表司改會認定任何人有罪。年度結果是參與者自願圈選的統計，不是抽樣民調。事件圖片引用自各媒體報導，版權屬原媒體，網站上標有出處與原文連結；權利人如不同意使用，請與我們聯絡。

## 技術

網站是純靜態網頁（HTML、CSS、JavaScript），部署在 GitHub Pages，沒有自己的伺服器；圈選資料只存在 Google 表單與司改會的試算表。

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網站入口 |
| `assets/` | 程式、樣式與網站設定（`config.js`） |
| `data/events.js` | 各年度事件、相關新聞與結果 |
| `data/polls.js` | 其他司法民調資料 |
| `data/ccu-survey.js` | 中正大學107–114年度六項調查數據、訪問資訊與來源 |
| `assets/ccu-survey.js` | 中正大學調查專頁與預覽 |
| `assets/survey-charts.js` | 中正與遠見調查共用的圖卡、折線與標籤避讓 |
| `data/gvm-survey.js` | 遠見社會信任調查數據與各筆來源 |
| `assets/gvm-survey.js` | 司法民調中的遠見調查詳情（`/#gvm-survey`）、法官信任度預覽與提示互動 |
| `images/` | 事件圖片與社群分享縮圖 |
| `docs/部署說明.md` | 維護者用的部署、Google 表單設定與年度更新流程 |

本機預覽：在專案資料夾執行 `python3 -m http.server`，再打開 http://localhost:8000/。

## 聯絡

內容有誤或想提供建議，歡迎透過 [司改會官網](https://www.jrf.org.tw/) 與我們聯絡，或在本儲存庫開 issue。

中正大學調查維護：112年度固定使用2024年1月訪問1,804人的版本，不混用3,001人版本；年度依報告所屬年度標示。新增年度前須確認六項原始數值、研究版本及來源，不自動延伸序列。

檢查：`node --test tests/*.test.cjs`。

遠見調查維護：調查不固定每年辦理，缺年不補0；2006–2017年採2017年版警政工作年報，2021年僅收已確認的法官信任度。2024年方法不可套用其他年度。各筆資料的 `sourceId` 對應同檔來源。
