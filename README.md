# 年度司法大事記

民間司法改革基金會（司改會）每年整理當年度台灣重要的司法事件，邀請大家一起回顧，並圈選出心中最重要的幾件。

網站：https://vote.jrf.org.tw/

## 網站內容

- **票選年度司法大事**：依時間順序回顧當年度的司法事件，每人最多圈選 5 件。
- **年度結果**：圈選截止後，公布「大家心中的年度大事」與「司改會評選」的對照。
- **歷年回顧**：保存每一年的事件與結果。
- **司法民調**：整理司法院、中正大學犯罪研究中心、台灣民意基金會等單位的司法相關民調，附原始出處。

## 圈選資料怎麼處理

- 網站把你圈的事件預先填進司改會的 Google 表單，你登入 Google 帳號後在表單頁送出。每個 Google 帳號限填一次，用來避免重複送出與灌票。
- 表單會記錄你的 Google 帳號電子郵件，只用來確認每人送出一次，不公開、不另作他用，結果公布後刪除。
- 結果代表參與者的關注，不是具代表性的抽樣民調。

## 免責聲明

事件內容由司改會依公開的新聞報導、判決與官方資料整理，反映整理當時已知的資訊，僅供公共討論參考，不是法律意見。尚未判決確定的案件，被告依法推定無罪；列入大事記不代表司改會認定任何人有罪或有過失。外部新聞連結的內容由各媒體負責。完整說明見網站的「關於」頁。

## 技術

網站是純靜態網頁（HTML、CSS、JavaScript），部署在 GitHub Pages，沒有自己的伺服器；圈選資料只存在 Google 表單與司改會的試算表。

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網站入口 |
| `assets/` | 程式、樣式與網站設定（`config.js`） |
| `data/events.js` | 各年度事件、相關新聞與結果 |
| `data/polls.js` | 司法民調資料 |
| `images/` | 事件圖片與社群分享縮圖 |
| `docs/部署說明.md` | 維護者用的部署、Google 表單設定與年度更新流程 |

本機預覽：在專案資料夾執行 `python3 -m http.server`，再打開 http://localhost:8000/。
