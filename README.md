# 年度司法大事記

民間司法改革基金會（司改會）每年整理當年度台灣重要的司法事件，邀請大家一起回顧，並圈選出心中最重要的幾件。

網站：https://vote.jrf.org.tw/

## 網站內容

- **票選年度司法大事**：依時間順序回顧當年度的司法事件，每人最多圈選 5 件。
- **年度結果**：圈選截止後，公布「大家心中的年度大事」與「司改會評選」的對照。
- **歷年回顧**：保存每一年的事件與結果。
- **司法民調**：整理司法院、中正大學犯罪研究中心、台灣民意基金會等單位的司法相關民調，附原始出處。

## 圈選資料怎麼處理

- 不需要登入，不蒐集姓名、電子郵件等個人資料。
- 送出時只記錄圈選的事件代碼。送出前會經過 Cloudflare Turnstile 人機驗證，阻擋程式自動灌票；圈選結果存放在司改會的 Google 表單，由司改會統計。
- 同一個瀏覽器只能送出一次，但無法防止真人換瀏覽器重複送出，所以結果代表參與者的關注，不是具代表性的抽樣民調。

## 技術

網站是純靜態網頁（HTML、CSS、JavaScript），部署在 GitHub Pages。送出圈選時，網站先把資料交給一個 Cloudflare Worker，由它檢查人機驗證與圈選內容，再寫入 Google 表單；表單網址只存在 Worker 的密鑰裡。

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網站入口 |
| `assets/` | 程式、樣式與網站設定（`config.js`） |
| `data/events.js` | 各年度事件、相關新聞與結果 |
| `data/polls.js` | 司法民調資料 |
| `images/` | 事件圖片與社群分享縮圖 |
| `worker/` | 送出服務（Cloudflare Worker） |
| `docs/部署說明.md` | 維護者用的部署、Google 表單設定與年度更新流程 |

本機預覽：在專案資料夾執行 `python3 -m http.server`，再打開 http://localhost:8000/。
